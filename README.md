# Overview
This was a project created for YouCode 2025, which won first place in the SAP beginner stream. At the time, the app only had a working frontend.
Since then, I have implemented a complete backend with a complete database, in-app chatting and user authentication using firebase and firestore.

## What is SustainaBite?

As university students, we realized that we often struggled with expensive food prices and often not being able to cook as much as we would like and the food often ends up going to waste.
What if we could buy small quantities of food at bulk prices? This is the solution that we aimed to solve. With SustainaBite, you are able to be matched with people who want to buy similar
groceries as you so you are able to buy them in bulk and share with them!


## Tech stack
### Frontend
- **React Native** – The core framework for building cross-platform mobile applications (iOS and Android).
- **Expo** – Used as a development toolchain to simplify building, testing, and deploying the React Native app.

### Backend / Cloud Services
- **Firebase** – Provides a suite of cloud services for mobile apps.
  - **Firebase Authentication** – Handles secure user authentication, including email/password sign-up and login.
  - **Cloud Firestore** – A NoSQL database used for storing user data, chat messages, and app-related content in real-time.

### Programming Language
- **JavaScript** – Used throughout the project for both frontend and backend logic.

---

## Features
1. **User Authentication**
   - Sign up and log in using Firebase Authentication.
   - Secure storage of user credentials and profile data.

2. **In-App Chat**
   - Real-time messaging powered by Firebase Firestore.
   - Supports multiple users and instant updates.

3. **Data Storage**
   - Firestore database stores user profiles, messages, and app-specific content.
   - Data is synchronized in real-time across all connected devices.

4. **Cross-Platform Support**
   - React Native + Expo allows the app to run seamlessly on both Android and iOS devices
